# RE Agent — Reports

Reverse engineering reports published by the [RE Agent](https://github.com/zerocactus/RE-Agent) — an AI agent built on TrueForge that analyzes binaries in a hardened sandbox and produces human-reviewed triage reports.

Every report in this repository was:
1. Generated by the RE Agent's static + dynamic analysis pipeline
2. Reviewed and approved by a human before publication
3. Opened as a pull request to preserve the review trail

## How reports appear

Reports arrive as pull requests. Merged reports live in `reports/<binary-name>.md`.
